# Project instructions

Read and follow CLAUDE.md before working in this project. Its prompt logging rule applies to every coding assistant used here.

- Append user prompts and factual response summaries to prompts.txt. Preserve the existing history.
- Use ISO 8601 timestamps. Label imported history and distinguish the recording time from an unknown original prompt time.
- Do not log credentials, hidden system instructions, or internal tool transcripts. Mark any credential redaction explicitly.
- The user authorized source publication to https://github.com/walterg1010/signal. Keep credentials and runtime data local. Deployment and publication to other repositories require a separate user request.
- Document features as implemented only after they work. Describe unfinished features as planned.
